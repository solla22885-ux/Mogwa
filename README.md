# Mogwa

한국투자증권 Open API의 해외 주식 잔고와 실시간 시세를 WebView2 대시보드에 표시하는 C++20/MFC 포트폴리오 프로젝트입니다. API 인증정보가 없는 환경에서는 외부 호출 없이 데모 데이터로 실행되므로 검토자가 바로 화면과 데이터 흐름을 확인할 수 있습니다.

![Mogwa dashboard preview](dashboard-preview.png)

## 구현 범위

- OAuth 토큰 발급, SQLite 캐시, 만료 5분 전 선제 갱신
- 해외 주식 잔고 및 환율 조회
- WebSocket 종목 구독과 UI 스레드 메시지 전달
- 평가액·손익·보유 비중 실시간 재계산
- Canvas 기반 실시간 자산 추이, 보유 비중 도넛, 손익 기여도 및 수익률·비중 버블 맵
- 종목 검색·정렬, 차트 툴팁, 차트 클릭 필터와 종목별 실시간 스파크라인
- OpenAI 기반 포트폴리오 코멘트(선택 기능)
- API 오류, 타임아웃, 잘못된 JSON 및 비정상 시세 방어
- 실행 파일 기준 상대 경로로 UI 리소스 배포

## 구조

```text
Investment/   KIS REST/WebSocket 연동, 설정 및 거래 도메인
DB/           토큰 영속화와 스키마 관리
L2Webview/    WebView2 수명 주기 및 네이티브-JavaScript 브리지
View/         포트폴리오 대시보드
lib/          SQLite, 문자열, HTTP 보조 코드
```

네트워크 계층은 데이터를 임시 객체에 파싱한 뒤 성공한 경우에만 현재 상태를 교체합니다. WebSocket 작업은 별도 스레드에서 수행하며, 수신 데이터의 소유권은 `PostMessage` 성공 시에만 UI 스레드로 이전합니다. 종료 시 활성 소켓을 취소해 동기 읽기 때문에 종료가 멈추지 않도록 했습니다.

## 실행

요구 사항은 Visual Studio 2022, C++ 데스크톱/MFC 워크로드, WebView2 Runtime입니다. 솔루션에서 `Debug | x64` 또는 `Release | x64`로 빌드합니다.

인증정보를 설정하지 않고 실행하면 `DEMO DATA` 배지가 표시됩니다. 실제 API를 사용하려면 [.env.example](.env.example)의 이름을 참고하여 Windows 사용자 환경변수를 설정한 뒤 앱을 다시 실행합니다. `.env` 파일을 직접 읽지는 않으며, 비밀값은 소스와 실행 인자에 남기지 않습니다.

> 과거에 저장소나 빌드 산출물에 실제 키를 넣었다면 코드에서 삭제하는 것만으로는 안전하지 않습니다. 해당 제공자 콘솔에서 기존 키를 폐기하고 새 키를 발급해야 합니다.

## 주요 설계 의도

- 리뷰 가능한 작은 계층을 유지하면서 UI, 외부 API, 저장소 책임을 분리했습니다.
- 데모와 실계정 경로를 명시적으로 구분해 샘플 데이터가 실제 잔고에 섞이지 않습니다.
- SQLite prepared statement의 바인딩 개수와 실행 결과를 검사하여 실패를 성공으로 오인하지 않습니다.
- 외부 CDN이 로드되지 않아도 네이티브 초기화 메시지는 전송되어 목록과 요약은 계속 동작합니다.
- 모든 차트를 순수 Canvas로 그려 외부 프론트엔드 라이브러리 없이 오프라인에서도 동일하게 동작합니다.

실거래 주문 기능은 의도적으로 포함하지 않았습니다. 이 프로젝트는 조회와 실시간 데이터 처리 품질을 보여 주는 read-only 예제입니다.
